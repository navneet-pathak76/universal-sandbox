# Contributing

1. Keep established equations separate from experimental models.
2. Document units at every public API boundary.
3. Include tests for an analytical or reference case when changing the integrator.
4. Test timestep convergence and monitor energy/momentum error for long runs.
5. Label preset data with source, epoch, frame, uncertainty, and license when those are known.
6. Never commit API keys, local environment files, or private data.
7. The project is local-first. No Vercel deployment is configured.
